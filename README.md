# 丝杆取料与二次涂油视觉检测系统

第一阶段框架：识别员工是否从涂油机工位取出已完成设备涂油的丝杆，以及取料后是否
执行了人工二次涂油动作。本版本只做 **UI、整体流程框架、训练视频录制**；模型训练在
另一个项目中完成，本项目暂不训练模型。

- 桌面端：PySide6 + QFluentWidgets，复用海康 HCNetSDK/PlayCtrl 相机接入
- 业务层：工位/ROI 配置 → 检测器 → 时序证据 → 单根物料状态机 → 事件与复核
- 物料关联：跟踪机器涂油盘，按盘体局部几何维护 4 个动态槽位；手部/刷子独立跟踪
- 录制：按分段保存相机原始视频，并生成训练用 JSON 元数据
- 无模型可运行：`null` 检测器保证不伪造事件；`演示模式` 用脚本数据联调 UI/流程

## 快速开始

```bash
uv sync
uv run python main.py
```

首次运行会在用户主目录下创建统一的数据目录：

- 所有平台：`~/OilCheckData/`（Windows 为 `%USERPROFILE%\OilCheckData\`）
- 配置、日志、截图、事件、训练录制都放在这里，便于备份和迁移
- 可用 `OILCHECK_DATA_ROOT` 覆盖

如需把配置/日志/事件/录制写回仓库目录：

```bash
OILCHECK_DATA_ROOT=$(pwd) uv run python main.py
```

## 当前边界

- 不做模型训练与真实推理；`detector.kind=yolo` 仅保留适配器骨架。
- 不承诺永久稳定的物理物料身份；取料后建立 `Part-A` 等操作记录，关联冲突转待确认。
- 不检测员工离岗、上料数量、设备启停、放料和油脂涂层质量。
- 第一版未启用事件前后视频片段；复核页保留入口与字段，片段保存作为后续项。
