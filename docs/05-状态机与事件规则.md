# 05 状态机与事件规则

实现文件：`app/oilcheck/pipeline.py`。配置参数见
[02-配置说明.md](02-配置说明.md) 的 `pipeline` 小节。

## 1. 设计原则

1. 机器涂油盘与人工操作**并行建模**：盘体/4 槽位状态和逐根物料操作记录互不阻塞。
2. 先看证据再改状态；遮挡、盘体定位失效、关联冲突进入 `UNKNOWN` / 待确认，
   不强行判定成功或失败。
3. 预测轨迹只用于维持跟踪连续性，不作为真实接触、取料或涂油证据。
4. 每个输出事件都带 `reason` 与证据列表，便于现场复盘和阈值调整。

## 2. 状态域

### 2.1 槽位占用（机器盘）

```text
UNKNOWN ──稳定看到丝杆──► OCCUPIED
   ▲                         │
   │遮挡/定位失效超时         │清晰可见且连续无丝杆
   └─────────────────────────▼
                           EMPTY
```

| 状态 | 含义 |
| --- | --- |
| `OCCUPIED` | 确认槽位有物料 |
| `EMPTY` | 清晰可见且连续无物料 |
| `UNKNOWN` | 遮挡、盘体定位不可靠或证据冲突；**不自动转为 EMPTY** |

### 2.2 人工操作（逐根物料）

```text
（取料确认）
    ▼
 PICKED
    │ 刷子接近物料
    ▼
OILING_CANDIDATE ──证据不足/遮挡──► PENDING_CONFIRMATION
    │                                   │
    │ 关联冲突                          │ 重新出现唯一关联
    ▼                                   ▼
IDENTITY_UNCERTAIN ◄──────────── OILING_CANDIDATE
    │
    │ 刷子相对运动 + 时长满足
    ▼
OILING_CONFIRMED
```

| 状态 | 说明 | 是否算完成 |
| --- | --- | --- |
| `NOT_STARTED` | 未确认取料 | 否 |
| `PICKED` | 已确认从机器盘取出 | 否 |
| `OILING_CANDIDATE` | 检测到刷子接近物料，正在累计证据 | 否 |
| `PENDING_CONFIRMATION` | 遮挡、证据不足或取料遮挡超时，等待复核 | 否 |
| `IDENTITY_UNCERTAIN` | 无法可靠关联到具体物料/刷子轨迹 | 否 |
| `OILING_CONFIRMED` | 刷子相对运动规则满足 | 是（仅动作证据） |

## 3. 每帧证据

| 证据 | 计算方式 |
| --- | --- |
| `slot.box` | `tray_box` + `slot_layout` 局部几何 |
| `slot.visibility` | 手部是否覆盖、盘体是否可靠 |
| `screw_in_slot` | 丝杆检测中心/重叠比例落入槽位框 |
| `hand_cover` | 手部框与槽位框重叠比例 ≥ `slot_hand_occlusion_ratio`，或手中心在槽内 |
| `hand_near` | 手部中心在槽位外扩 `slot_hand_margin` 范围内 |
| `pick_candidate` | `OCCUPIED` 槽位出现手部接近 |
| `part_box` | 手部附近、离开槽位的丝杆检测；缺失时可用手框作为关联代理 |
| `brush_near_part` | 刷子中心到物料中心距离 ≤ `brush_part_distance` |
| `brush_motion` | 刷子相对物料中心的位移累计 / 帧对角线 |
| `brush_duration` | 刷子持续接近物料的累计时间 |

## 4. 槽位状态规则

1. 盘体缺失或 `reliable=false`：`visibility=UNRELIABLE`，暂停占用状态切换。
2. 手部覆盖且无丝杆证据：保持原状态；超过 `slot_occlusion_unknown_s` → `UNKNOWN`。
3. 手部覆盖但丝杆仍可见：保持/确认 `OCCUPIED`，不触发遮挡待确认。
4. 清晰可见且连续无丝杆 ≥ `slot_empty_confirm_s` → `EMPTY`。
5. `UNKNOWN` 恢复清晰可见后，仍需满足空置/有料确认时长才能切换。

## 5. 取料规则

### 5.1 候选与确认

| 条件 | 动作 |
| --- | --- |
| `OCCUPIED` 槽位出现手部接近 | 记录取料候选、手部轨迹 ID |
| 手离开后丝杆仍在原位 ≥ `pick_abort_s` | 取消候选 |
| 槽位稳定变空且 `pick_window_s` 内有手部交互 | 建立操作 → `PICKED`，发 `PICK/CONFIRMED` |
| 槽位无手部交互变空 | 只更新槽位状态，不建立操作 |
| 遮挡超过 `occlusion_timeout_s` 且取料候选未决 | 建立 `PENDING` 操作，发 `PICK/NEEDS_REVIEW` |
| `PENDING` 操作随后观察到槽位清晰变空 | 补发 `PICK/CONFIRMED`，转入 `PICKED` |
| `PENDING` 操作随后丝杆重新稳定可见 | 取消该取料候选，不产生 CONFIRMED |

逻辑物料编号：

```text
Part-A, Part-B, ... Part-Z, Part-AA, ...
operation_id = op-<station_id>-<seq:04d>
```

每个工位独立递增；事件同时记录 `source_slot` 与 `operation_id`。

### 5.2 并行规则

- 一次取料只影响来源槽位的操作记录；其他槽位继续独立更新。
- 机器盘继续上下移动或处理其他槽位，不会改变已建立的人工操作状态。
- 多条操作可以同时存在，例如 Part-A 处于 `OILING_CANDIDATE`，Part-B 已 `PICKED`，
  Slot 3/4 仍 `OCCUPIED`。

## 6. 二次涂油规则

### 6.1 证据累计

```text
刷子与物料中心距离 ≤ brush_part_distance
  → PICKED 进入 OILING_CANDIDATE
  → 帧间隙 ≤ brush_max_gap_s：累计时长 += 间隙
  → 累计刷子相对物料位移
  → 时长 ≥ brush_min_duration_s 且位移 ≥ brush_min_motion
  → MANUAL_OILING/CONFIRMED，进入 OILING_CONFIRMED
```

- `brush_require_hand=true` 时还要求关联手部本帧可见且靠近物料。
- 刷子离开超过 `brush_max_gap_s`：
  - 已有时长/位移但未满足 → `PENDING_CONFIRMATION`，发
    `MANUAL_OILING/NEEDS_REVIEW`（`insufficient_brush_evidence`）；
  - 几乎没有动作 → 回到 `PICKED`，不发事件。
- 刷子重新出现且关联唯一时，允许从 `PENDING_CONFIRMATION` /
  `IDENTITY_UNCERTAIN` 恢复到 `OILING_CANDIDATE` 重新累计。

### 6.2 身份关联

- 同一刷子同时接近多根物料，且距离差 ≤ `identity_ambiguity_margin`：
  相关操作进入 `IDENTITY_UNCERTAIN`（`MULTI_PART_BRUSH_AMBIGUITY`）。
- 同一物料附近出现多条刷子轨迹：`MULTI_BRUSH_AMBIGUITY`。
- 操作超过 `identity_timeout_s` 仍无法观察到物料/手部关联：`PART_LOST`。
- 身份不确定期间**不累计涂油证据**，避免把结果错归到另一根物料。

## 7. 事件

| 字段 | 说明 |
| --- | --- |
| `event_type` | `PICK` / `MANUAL_OILING` |
| `result` | `CONFIRMED` / `NEEDS_REVIEW` |
| `timestamp_start/end` | 取料候选或涂油候选起点 / 判定时刻 |
| `evidence.operation_id` | 操作记录 ID |
| `evidence.source_slot` | 来源槽位 |
| `evidence.pickup_status` | `CONFIRMED` / `PENDING` / `UNCONFIRMED` |
| `evidence.identity_status` | `ASSOCIATED` / `UNCERTAIN` |
| `evidence.reason` | 规则原因 |
| `evidence.evidence` | 证据列表（手部接近、槽位变空、刷子相对运动等） |

常见 `reason`：

| reason | 含义 |
| --- | --- |
| `pick_confirmed` | 手部交互后槽位稳定变空 |
| `PICK_OCCLUSION_TIMEOUT` | 取料过程中遮挡超时，等待复核 |
| `pick_confirmed_after_occlusion` | 遮挡后恢复可见且槽位变空，补确认 |
| `brush_relative_motion_satisfied` | 刷子相对运动时长/位移满足 |
| `insufficient_brush_evidence` | 刷子接近但动作证据不足 |
| `MULTI_PART_BRUSH_AMBIGUITY` | 一根刷子对应多根候选物料 |
| `MULTI_BRUSH_AMBIGUITY` | 一根物料对应多条刷子轨迹 |
| `PART_LOST` | 物料长时间无法观测/关联 |
| `SCREW_REAPPEARED` | 待确认取料后丝杆重新出现，取消候选 |

## 8. 遮挡与异常策略

| 场景 | 处理 | 禁止 |
| --- | --- | --- |
| 手部短时遮挡 | 保留手部轨迹，重新出现后按空间关联 | 把手消失当作操作结束 |
| 刷子被手遮挡 | 保留历史轨迹；恢复后继续累计 | 把预测位置当作涂油证据 |
| 槽位被手遮挡 | 维持状态或转 `UNKNOWN` | 直接判 `EMPTY` |
| 盘体上下移动/模糊 | 更新盘体跟踪；不可靠时暂停槽位切换 | 用旧 ROI 判断离盘 |
| 多根物料/多把刷子交叉 | 独立维护候选，冲突时 `IDENTITY_UNCERTAIN` | 强行分配物料 ID |
| 长时间完全遮挡 | 停止预测累积，等待复核 | 无限延长预测并累计证据 |

## 9. 阈值调优方法

1. 用训练录制页采集正负样本：真实取料/涂油、普通拿取、调整位置、短暂停留、遮挡。
2. 离线回放，按 `reason` 统计误报/漏报/待确认。
3. 优先调整：
   - 取料误报多 → 提高 `slot_empty_confirm_s`、`pick_window_s`；
   - 槽位状态跳变 → 提高 `slot_occupied_confirm_s` / `slot_empty_confirm_s`；
   - 盘体移动时误判 → 检查 `TrayTracker` 关联距离与最小置信度；
   - 涂油误报多 → 提高 `brush_min_duration_s` / `brush_min_motion`；
   - 涂油漏报多 → 检查刷子检测召回与 `brush_part_distance`；
   - 身份不确定多 → 提高检测分辨率，或减小 `identity_ambiguity_margin`。
4. 每次只改一个参数，记录对应视频片段与统计结果。

## 10. 已知限制

- 单目 2D 位置无法证明真实接触；涂油完成仅代表可观察动作满足规则。
- 盘体若存在旋转/透视变化，轴对齐 `slot_layout` 会偏移，需要旋转框/关键点。
- 丝杆被取出后若完全离开视野，身份关联只能降级为不确定/待确认。
- 两根外观相同的丝杆交叉、多把刷子同时操作时，身份可能无法唯一确定。
- 涂油完成不代表油脂用量、覆盖范围或涂层质量合格。
