# 05 状态机与事件规则

对应实现文档第 5~8 节。实现位置：`app/oilcheck/pipeline.py`、
`app/oilcheck/types.py`。

## 1. 设计原则

- 视觉 Track ID 与业务任务 ID 分离；
- 取料、手持、刷涂分别维护状态；
- 证据不足输出待确认，不强行 OK/NG；
- 事件使用视频时间戳，不用帧序号计算时长。

## 2. 状态域

### 2.1 取料状态 PickStatus

| 值 | 含义 |
| --- | --- |
| `CANDIDATE` | 手部已接近丝杆，证据链未完成 |
| `CONFIRMED` | 共同运动 + 离盘 + 进入手持区 + 持续关联 |
| `UNKNOWN` | 证据不足（遮挡、歧义），等待人工/重关联 |

### 2.2 手持状态 HoldingStatus

| 值 | 含义 |
| --- | --- |
| `HOLDING` | 当前帧或重关联后持有丝杆 |
| `LOST` | 超过 `holding_lost_timeout_s` 无法关联 |
| `RELEASED` | 任务结束 |

### 2.3 刷涂状态 OilingStatus

| 值 | 含义 |
| --- | --- |
| `WAITING` | 等待刷头接触 |
| `CONTACT` | 刷头接触，尚无有效运动 |
| `BRUSHING` | 接触 + 有效相对运动 |
| `COMPLETED` | 覆盖/时长达到阈值 |

### 2.4 任务阶段 TaskStage

```text
WAITING_PICK → PICK_CANDIDATE → LEAVING_TRAY → PICK_CONFIRMED
            → HOLDING → BRUSH_CONTACT → BRUSHING → OILING_COMPLETED
任意阶段证据不足 → PENDING_CONFIRMATION
明确违反工艺且证据充分 → NG
```

### 2.5 最终结果 TaskResult

| 值 | 条件 |
| --- | --- |
| `PROCESSING` | 任务进行中 |
| `OK` | 取料确认 + 接触 + 有效刷涂 + 覆盖达标 |
| `NG` | 可观测条件下确认未执行必要动作 |
| `PENDING_CONFIRMATION` | 遮挡、关联不确定、视频异常、部分证据不足 |

## 3. 每帧证据

- 丝杆/手/刷头跟踪结果；
- 手-丝杆距离、手与丝杆位移、相对位置变化；
- 丝杆是否在涂油盘区、是否进入手持区；
- 刷头工作点到丝杆轴线距离、轴向坐标；
- 各状态持续时间（基于视频时间戳）。

## 4. 取料规则

### 4.1 候选

同时满足：

1. 丝杆此前在 `tray_roi` 内被跟踪；
2. 手中心距丝杆 ≤ `pick_hand_distance`。

建立/复用业务任务，`pick_status=CANDIDATE`，阶段 `PICK_CANDIDATE`。
此时不发出确认事件。

### 4.2 确认

同时满足：

1. 手与丝杆共同运动累计 ≥ `pick_comotion_min_s`；
2. 丝杆离开涂油盘参考区域；
3. 丝杆中心进入 `hand_roi`；
4. 进入手持区后持续关联 ≥ `pick_confirm_s`；
5. 当前帧丝杆可见，且不存在距离接近的竞争候选。

→ `pick_status=CONFIRMED`、`holding_status=HOLDING`，发出
`PICK/CONFIRMED` 事件，阶段进入 `HOLDING`。

### 4.3 待确认

- 离盘后丝杆不可见、手仍在手持区 ≥ `pick_occlusion_timeout_s`；
- 同一只手存在多个距离接近的候选；
- 手带料离开但丝杆全程不可见。

→ `pick_status=UNKNOWN`、`final_result=PENDING_CONFIRMATION`，发出
`PICK/NEEDS_REVIEW`。丝杆重新出现并可唯一关联时仍可升级为确认。

### 4.4 取消

手离开且丝杆仍在涂油盘内 ≥ `pick_abort_s`：取消候选，不产生事件。

## 5. 手持关联规则

- 当前 `screw_track_id` 仍匹配 → 更新框、主轴、位置；
- Track 丢失 → 在未认领轨迹中按上一位置 + 手部附近重关联；
- 唯一候选 → `TRACK_REASSOCIATED`；
- 多候选或无候选 → `identity_status=UNCERTAIN`，暂停刷涂累计；
- 超过 `holding_lost_timeout_s` → `HOLDING LOST`，阶段待确认；
- 丝杆恢复 → 回到 `HOLDING` 并继续累计。

## 6. 刷涂规则

### 6.1 接触

刷头工作点到丝杆轴向线段的距离 ≤ `brush_contact_distance`，且刷头在本帧真实
检测到（不使用预测框作为接触证据）。首次接触发出 `BRUSH_CONTACT/CONFIRMED`。

### 6.2 有效运动

将工作点投影到丝杆局部坐标，累计
`|Δ轴向| / 丝杆可见长度`。累计运动 ≥ `brush_min_motion` 且接触时长 ≥
`brush_min_duration_s` → `BRUSHING`。

### 6.3 完成

覆盖区段比例 ≥ `coverage_required`，且时长/运动阈值满足 →
`OILING_COMPLETED`，`final_result=OK`，发出
`MANUAL_OILING/CONFIRMED` 与 `TASK_RESULT/CONFIRMED`。

### 6.4 不足

- 有接触但无有效运动 → 保持 `CONTACT`；
- 任务结束（手和丝杆都离开）时：
  - 有部分接触/运动/覆盖或身份不确定 → `PENDING_CONFIRMATION`；
  - 可观测条件下完全没有刷涂证据 → `NG`；
- `oiling_wait_timeout_s > 0` 时，取料后超时未接触可判 `NG`。

## 7. 事件

| 事件 | 触发 | 结果 |
| --- | --- | --- |
| `PICK` | 取料确认 / 取料待确认 | `CONFIRMED` / `NEEDS_REVIEW` |
| `BRUSH_CONTACT` | 每次有效接触区间开始 | `CONFIRMED` |
| `MANUAL_OILING` | 刷涂完成 | `CONFIRMED` |
| `TASK_RESULT` | 任务终态 | `CONFIRMED` / `UNCONFIRMED` / `NEEDS_REVIEW` |

事件证据包含任务 ID、轨迹 ID、接触区间、覆盖区段、覆盖比例、有效刷涂时长、
相对运动量、原因码等。

## 8. 遮挡与异常策略

- 丝杆完全遮挡：短时预测/重关联；不确定时待确认；
- 视频断流、严重丢帧：不自动补判 OK；
- 刷头不可见：不累计进度；
- 多任务并行：默认单活动任务；`single_active_task=false` 可扩展；
- 完成即结束任务；存储盘识别不在本期范围。

## 9. 阈值调优方法

1. 用真实完整周期视频回放；
2. 先调 `pick_hand_distance`、`pick_comotion_min_s`、`pick_confirm_s`，
   保证取料不漏报/不误报；
3. 再调 `brush_contact_distance`、`brush_min_motion`、
   `brush_min_duration_s`；
4. 最后按工艺要求设置 `coverage_segments` / `coverage_required`；
5. 统计待确认比例，若过高优先检查 ROI、刷头关键点与遮挡。

## 10. 已知限制

- 单目顶视无法证明周向覆盖或油脂附着量；
- 手持丝杆快速旋转时主轴估计会抖动；
- 刷头框中心可能不代表工作端，建议使用关键点；
- 本期未启用事件前后视频片段。
