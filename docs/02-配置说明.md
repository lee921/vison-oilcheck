# 02 配置说明

## 1. 配置放在哪里

```text
<数据目录>/config/app.json        应用级参数（布局、帧率、目录）
<数据目录>/config/cameras.json    相机清单
<数据目录>/config/oilcheck.json   工位、ROI、判定阈值、录制参数
```

数据目录优先级：

1. 环境变量 `OILCHECK_DATA_ROOT`（相对路径基于当前工作目录）；
2. 兼容旧变量 `VISION_CRAFT_DATA_ROOT`；
3. 默认：用户主目录下的 `~/OilCheckData`（Windows 为 `%USERPROFILE%\OilCheckData`）。

所有持久化数据统一放在该目录，不再写入 `~/.config`、`%LOCALAPPDATA%` 或
`~/Library/Application Support`。

首次运行会从仓库 `config/` 复制模板。**修改仓库模板不会自动覆盖已存在的数据目录
配置**；现场调试请改数据目录下的文件，或删除数据目录后重新复制。

> 旧版本曾把数据放在 `~/.config/oilcheck`。升级时把该目录内容整体移动到
> `~/OilCheckData` 即可（本机已完成迁移）。

开发时建议把数据写回仓库，便于查看：

```bash
OILCHECK_DATA_ROOT=$(pwd) uv run python main.py
```

## 2. app.json

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `layout` | int | `1` | 旧预览布局，当前监控页不使用 |
| `ui_fps` | int | `15` | 监控画面刷新帧率 |
| `decode_max_fps` | int | `15` | 相机解码上限 |
| `offline_timeout_s` | int | `10` | 相机离线判定超时 |
| `snapshot_dir` | str | `snapshots` | 截图目录（相对数据目录） |
| `log_dir` | str | `logs` | 日志目录（相对数据目录） |
| `relay` | object | - | 旧项目继电器配置，当前流程不使用 |

## 3. cameras.json

数组，每个相机：

| 字段 | 说明 |
| --- | --- |
| `id` | 唯一 ID，`oilcheck.json` 用它关联工位 |
| `name` | 显示名称 |
| `enabled` | 是否启用 |
| `ip` / `port` / `username` / `password` | 海康设备信息；密码支持 `env:VAR_NAME` |
| `channel` | 通道号，默认 1 |
| `stream_type` | `main` / `sub` |
| `preferred_mode` | `decode`（推荐）或 `direct` |
| `reconnect` | 重连开关、最大退避、离线超时 |

第一阶段推荐 `decode`：业务层需要帧数据做检测和录制，直连渲染模式拿不到 BGR 帧。

## 4. oilcheck.json

### 4.1 顶层

```json
{
  "version": "1.0",
  "pipeline": { ... },
  "recording": { ... },
  "stations": [ ... ]
}
```

### 4.2 pipeline：判定参数

盘体与槽位：

| 字段 | 默认 | 含义 |
| --- | --- | --- |
| `max_fps` | 15 | 状态机处理上限 |
| `tray_max_distance` | 0.20 | 盘体相邻帧关联的最大中心距离（按帧对角线归一化） |
| `tray_max_missing_s` | 1.0 | 盘体短时漏检保留时间 |
| `tray_min_confidence` | 0.30 | 低于该置信度的 tray 检测不参与跟踪 |
| `tray_motion_speed` | 0.05 | 判定盘体 MOVING/STILL 的速度阈值 |
| `slot_occupied_confirm_s` | 0.25 | 连续看到丝杆多久才确认 OCCUPIED |
| `slot_empty_confirm_s` | 0.60 | 清晰可见且无丝杆多久才确认 EMPTY |
| `slot_occlusion_unknown_s` | 2.0 | 遮挡/盘体不可靠持续多久转 UNKNOWN |
| `slot_hand_occlusion_ratio` | 0.15 | 手部框覆盖槽位框的比例阈值 |
| `slot_hand_margin` | 0.03 | 手部“接近槽位”的外扩比例 |

取料：

| 字段 | 默认 | 含义 |
| --- | --- | --- |
| `pick_abort_s` | 0.5 | 手离开后丝杆仍在原位多久取消取料候选 |
| `occlusion_timeout_s` | 2.0 | 取料候选被遮挡多久后转待确认 |
| `pick_window_s` | 2.0 | 槽位变空与手部交互之间的最大关联窗口 |
| `event_cooldown_s` | 1.0 | 同一操作同类事件最小间隔 |

二次涂油：

| 字段 | 默认 | 含义 |
| --- | --- | --- |
| `brush_part_distance` | 0.08 | 刷子与物料中心的关联距离（归一化） |
| `brush_min_duration_s` | 1.5 | 刷子持续接近物料的累计时长下限 |
| `brush_max_gap_s` | 0.8 | 刷子离开后允许继续累计的最大间隙 |
| `brush_min_motion` | 0.15 | 刷子相对物料的累计位移下限 |
| `brush_require_hand` | true | 是否要求关联手部同时可见且靠近物料 |
| `identity_timeout_s` | 2.0 | 物料/手部关联丢失多久转 IDENTITY_UNCERTAIN |
| `identity_ambiguity_margin` | 0.02 | 多个候选距离差小于该值时判为身份歧义 |
| `completed_retain_s` | 10.0 | 完成的操作记录保留时长 |
| `operation_max_active` | 8 | 同时保留的最大操作记录数 |

兼容字段 `oiling_min_duration_s` / `oiling_max_gap_s` / `oiling_min_motion` /
`track_*` / `pick_confirm_s` / `part_reset_absent_s` 仍可解析，但新状态机不再使用；
设置页保存时会把刷子参数回写到 `oiling_*` 兼容字段。

### 4.3 手部/刷子跟踪参数

| 字段 | 默认 | 含义 |
| --- | --- | --- |
| `hand_track_max_distance` | 0.15 | 手部相邻帧关联距离 |
| `hand_track_max_missing_s` | 0.8 | 手部短时漏检保留 |
| `hand_track_min_hits` | 1 | 新轨迹确认帧数 |
| `brush_track_max_distance` | 0.15 | 刷子相邻帧关联距离 |
| `brush_track_max_missing_s` | 0.8 | 刷子短时漏检保留 |
| `brush_track_min_hits` | 1 | 新轨迹确认帧数 |

### 4.4 recording：录制参数

| 字段 | 默认 | 含义 |
| --- | --- | --- |
| `training_dir` | `recordings/training` | 相对数据目录或绝对路径 |
| `fps` | 15 | 录制目标帧率 |
| `segment_seconds` | 300 | 单个 MP4 分段时长 |
| `codec` | `mp4v` | OpenCV FourCC |
| `auto_start` | false | 服务启动后自动为每个工位相机开始录制 |
| `event_clips_enabled` | false | 预留；当前版本未实现事件片段 |

### 4.5 stations：工位

默认 `slot_mode=tray`，使用机器涂油盘 + 4 个动态槽位：

```json
{
  "station_id": "ST01",
  "name": "1号取料工位",
  "camera_id": "cam_6ca47a",
  "enabled": true,
  "slot_mode": "tray",
  "pick_roi":   {"kind": "rect", "points": [[0.28, 0.08], [0.72, 0.42]]},
  "tray_roi":   {"kind": "rect", "points": [[0.28, 0.08], [0.72, 0.42]]},
  "oiling_roi": {"kind": "rect", "points": [[0.10, 0.50], [0.48, 0.96]]},
  "slot_layout": [
    {"index": 1, "name": "1号槽", "x1": 0.02, "y1": 0.15, "x2": 0.23, "y2": 0.9},
    {"index": 2, "name": "2号槽", "x1": 0.27, "y1": 0.15, "x2": 0.48, "y2": 0.9},
    {"index": 3, "name": "3号槽", "x1": 0.52, "y1": 0.15, "x2": 0.73, "y2": 0.9},
    {"index": 4, "name": "4号槽", "x1": 0.77, "y1": 0.15, "x2": 0.98, "y2": 0.9}
  ],
  "slots": [],
  "detector": {
    "kind": "null",
    "model_path": "",
    "confidence": 0.5,
    "hand_label": "hand",
    "rod_label": "rod",
    "brush_label": "brush",
    "tray_label": "tray",
    "cycle_seconds": 18.0
  }
}
```

- `pick_roi`：盘体/取料搜索区域；旧配置没有 `tray_roi` 时自动使用它。
- `tray_roi`：盘体检测搜索区域；可省略，默认等于 `pick_roi`。
- `slot_layout`：4 个槽位相对 `tray` 框的局部归一化矩形；盘体上下移动时自动跟随。
  未配置时默认横向均分 4 槽。
- `oiling_roi`：人工二次涂油操作区。
- `slot_mode=fixed` 仍可解析旧 `slots`，但新状态机按盘体动态槽位运行。

约束：

- `station_id` 全局唯一；`camera_id` 必须存在于 `cameras.json`。
- `pick_roi`、`oiling_roi` 必须能解析；`slot_layout` 每项 `x1<x2`、`y1<y2`。
- `slot_mode=fixed` 时仍要求至少一个 `slots`（兼容旧配置）。

### 4.6 detector

| `kind` | 行为 |
| --- | --- |
| `null` | 不产生检测；槽位保持 UNKNOWN，不伪造事件（默认） |
| `simulated` | 生成盘体、4 槽位、手部、刷子脚本，用于 UI/流程联调；**不是现场结果** |
| `yolo` | 外部训练模型适配器；未安装 `ultralytics` 时给出明确错误 |

标签：`hand_label`、`rod_label`（丝杆）、`brush_label`、`tray_label` 必须与模型
类别名一致。

## 5. ROI 坐标与标定

### 5.1 坐标定义

所有 ROI 都是**相对原始视频帧的归一化坐标** `0~1`，原点在左上角：

```text
归一化 x = 像素 x / 视频宽度
归一化 y = 像素 y / 视频高度
```

矩形用两个对角点表示；多边形用至少 3 个顶点，按顺序首尾相连：

```json
{"kind": "rect", "points": [[0.30, 0.10], [0.70, 0.45]]}
{"kind": "polygon", "points": [[0.30, 0.10], [0.70, 0.10], [0.55, 0.45]]}
```

### 5.2 现场标定步骤（推荐：界面标定）

1. 打开“设置”页，点击“打开 ROI 标定”；
2. 选择工位，点击“打开相机”；
3. 点击“截取画面”冻结当前帧；
4. 选择“设置盘体区”或“设置涂油区”，在画面上拖拽矩形；拖到画面外会自动裁剪到边缘，
   画错可点“清除当前区域”重画；
5. 两个区域都设置好后点击“保存并应用”；
6. 程序会写入 `oilcheck.json` 并重新加载检测服务，监控页立即使用新 ROI；
7. 保存、取消或关闭标定窗口都会停止相机预览，避免预览在后台继续运行。

`slot_layout`（4 个槽位相对盘体框的局部几何）目前需手工编辑 JSON；界面标定只负责
盘体搜索区和人工二次涂油区。

也可以手工编辑配置：

1. 启动相机预览，点击监控页“截图”，得到一张 BMP（路径显示在提示中）。
2. 用任意看图工具读取截图分辨率与目标区域像素坐标。
3. 按 `像素 / 分辨率` 换算归一化坐标，写入 `oilcheck.json`。
4. 重启程序（或保存设置页后由服务重载）观察监控页 ROI 是否贴合。
5. 连续观察取料、手部遮挡、二次涂油过程，确认 ROI 覆盖完整动作范围。

标定建议：

- `pick_roi` / `tray_roi` 覆盖机器涂油盘上下移动的完整范围，盘体不要频繁越界。
- `slot_layout` 按盘体实际几何填写；盘体只做平移时可使用局部归一化矩形，若存在
  旋转/透视变化需改用关键点或旋转框。
- `oiling_roi` 覆盖人工涂油的完整操作空间，包含手部与刷子移动范围。
- 槽位之间不要重叠；盘体定位不稳时状态机会暂停槽位切换。
- 若相机分辨率变化，归一化 ROI 仍然有效；若相机位置/镜头变化，必须重新标定。

### 5.3 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 修改仓库配置后无效 | 运行时读取的是数据目录副本 | 改数据目录下的文件，或设置 `OILCHECK_DATA_ROOT=$(pwd)` |
| 工位不出现在下拉框 | `station_id`/`camera_id`/ROI 校验失败 | 查看日志 `oilcheck.config`，补全字段 |
| ROI 显示偏移 | 坐标系不是归一化，或用了预览窗口尺寸 | 用原始帧分辨率和归一化坐标 |
| 演示模式重启后消失 | 演示切换只作用于运行时 | 需要持久演示请把 `detector.kind` 改为 `simulated` |
