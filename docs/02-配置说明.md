# 02 配置说明

对应实现文档第 3、10 节。ROI 与阈值都应版本化，并支持现场快速调整。

## 1. 配置放在哪里

| 文件 | 运行位置 | 仓库模板 |
| --- | --- | --- |
| 应用参数 | `<数据目录>/config/app.json` | `config/app.json` |
| 相机 | `<数据目录>/config/cameras.json` | `config/cameras.json` |
| 检测 | `<数据目录>/config/oilcheck.json` | `config/oilcheck.json` |

数据目录默认 `~/OilCheckData/`，可用 `OILCHECK_DATA_ROOT` 覆盖。仓库中的
`config/` 只在首次运行时复制为模板；修改仓库文件不会自动影响运行配置。

## 2. app.json

| 字段 | 含义 |
| --- | --- |
| `layout` | 预览布局（1/4/9/16） |
| `ui_fps` | UI 刷新帧率 |
| `decode_max_fps` | 解码最大帧率 |
| `offline_timeout_s` | 相机离线判定 |
| `snapshot_dir` / `log_dir` | 截图/日志目录 |
| `relay` | 继电器输出（预留） |

## 3. cameras.json

海康设备信息：`id/name/enabled/ip/port/username/password/channel/stream_type/
preferred_mode/reconnect`。密码支持 `env:VAR_NAME`，推荐把密码放在环境变量
`OILCHECK_CAM_PASSWORD` 中，避免明文入库。

```json
"password": "env:OILCHECK_CAM_PASSWORD"
```

## 4. oilcheck.json

### 4.1 顶层

```json
{
  "version": "2.1",
  "pipeline": { ... },
  "recording": { ... },
  "demo": { ... },
  "stations": [ ... ]
}
```

### 4.1.1 版本升级与自动迁移

`config/oilcheck.json` 只在**首次运行**时从仓库模板复制。之后模板更新了，
数据目录里的旧配置**不会自动变**——这是为了避免覆盖现场调好的 ROI。

程序启动时会按 `version` 做一次幂等迁移：

- 旧版本（`< 2.1`）会补齐新字段、把 `detector.kind=null` 改为 `yolo`、
  填入仓库权重路径、补充 `demo` 示例视频清单；
- 旧类别名 `oil_tray` / `brush_head` 会改成模型实际输出的
  `oil_station` / `brush`；
- 已有的 ROI、阈值、相机配置一律保留；
- 改动前把原文件备份为 `oilcheck.json.bak`。

所以服务器拉取新代码后**不需要手工改配置**。若想回到出厂配置，删掉
`<数据目录>/config/oilcheck.json` 重启即可（会重新复制模板）。

### 4.2 pipeline：取料事件

| 字段 | 默认 | 含义 |
| --- | --- | --- |
| `max_fps` | 15 | 检测最大帧率 |
| `pick_hand_distance` | 0.05 | 手-丝杆接近距离（按画面对角线归一化） |
| `pick_motion_min` | 0.01 | 单帧手/丝杆位移阈值 |
| `pick_relative_max` | 0.03 | 共同运动时相对位移上限 |
| `pick_comotion_min_s` | 0.25 | 共同运动最短累计时长 |
| `pick_confirm_s` | 0.30 | 进入手持区后持续关联确认时长 |
| `pick_abort_s` | 0.50 | 手离开后取消候选的时长 |
| `pick_occlusion_timeout_s` | 2.0 | 离盘后遮挡转待确认的时长 |
| `pick_ambiguity_margin` | 0.02 | 多候选歧义距离 |
| `pick_window_s` | 2.0 | 取料证据关联窗口 |

### 4.3 pipeline：跟踪

| 字段 | 默认 | 含义 |
| --- | --- | --- |
| `screw_track_max_distance` | 0.08 | 丝杆相邻帧关联距离 |
| `screw_track_max_missing_s` | 0.7 | 丝杆短时漏检保留 |
| `screw_track_min_hits` | 2 | 丝杆最少命中帧数 |
| `screw_track_max_active` | 16 | 最大同时轨迹 |
| `hand_track_*` | 0.15 / 0.8 / 1 | 手部跟踪 |
| `brush_track_*` | 0.15 / 0.8 / 1 | 刷头跟踪 |
| `tray_max_distance` / `tray_max_missing_s` / `tray_min_confidence` | 0.2 / 1.0 / 0.3 | 涂油盘定位 |

### 4.4 pipeline：刷涂与任务

| 字段 | 默认 | 含义 |
| --- | --- | --- |
| `brush_contact_distance` | 0.06 | 刷头工作端到丝杆轴线的接触距离 |
| `brush_min_duration_s` | 1.0 | 有效接触最短累计时长 |
| `brush_max_gap_s` | 0.6 | 允许的接触中断 |
| `brush_min_motion` | 0.15 | 沿丝杆轴向的最小累计相对位移（丝杆长度比例） |
| `brush_require_hand` | false | 是否要求同时检测到手部 |
| `coverage_segments` | 5 | 丝杆长度划分的覆盖区段数 |
| `coverage_required` | 0.60 | 判定完成所需覆盖比例 |
| `identity_timeout_s` | 2.0 | 目标身份关联丢失超时 |
| `holding_lost_timeout_s` | 2.0 | 手持丝杆丢失判定 |
| `oiling_wait_timeout_s` | 0.0 | 取料后等待刷涂超时（0 表示不判 NG） |
| `single_active_task` | true | 单活动任务模式 |
| `task_max_active` | 4 | 最大同时任务数 |
| `completed_retain_s` | 10.0 | 完成后在 UI 保留时长 |

旧版字段 `track_*`、`brush_part_distance`、`occlusion_timeout_s`、
`oiling_*` 等会在读取时自动映射到新字段，无需手工改现场配置。

### 4.5 recording：录制

同旧版：`training_dir`、`fps`、`segment_seconds`、`codec`、`auto_start`、
`event_clips_enabled`。

### 4.6 stations：工位

```json
{
  "station_id": "ST01",
  "name": "1号取料工位",
  "camera_id": "cam_6ca47a",
  "enabled": true,
  "tray_roi": {"kind": "rect", "points": [[0.28, 0.08], [0.72, 0.42]]},
  "hand_roi": {"kind": "rect", "points": [[0.1, 0.4], [0.48, 0.96]]},
  "brush_roi": {"kind": "rect", "points": [[0.1, 0.4], [0.55, 0.96]]},
  "exclude_rois": [
    {"kind": "rect", "points": [[0.0, 0.0], [0.1, 0.15]]}
  ],
  "detector": { ... }
}
```

| ROI | 用途 | 要求 |
| --- | --- | --- |
| `tray_roi` | 判断取料前存在、离盘 | 覆盖盘体及边缘缓冲，允许盘体上下移动 |
| `hand_roi` | 跟踪离盘后的丝杆 | 覆盖左手持料、移动、调整姿态范围 |
| `brush_roi` | 分析刷头接触与运动 | 与手持区有足够重叠，避免刚接触就出界 |
| `exclude_rois` | 物料盒等 | 完全排除推理，训练图像同步裁剪/屏蔽 |

旧配置中的 `pick_roi` 会迁移为 `tray_roi`，`oiling_roi` 迁移为 `hand_roi`，
`brush_roi` 缺省等于 `hand_roi`。

### 4.7 detector

```json
{
  "kind": "yolo",
  "model_path": "model/detect/exp/weights/best.pt",
  "confidence": 0.5,
  "iou": 0.7,
  "max_det": 100,
  "imgsz": 0,
  "device": "auto",
  "half": false,
  "raw_mode": true,
  "screw_label": "screw",
  "hand_label": "hand",
  "brush_label": "brush",
  "tray_label": "oil_station"
}
```

| 字段 | 说明 |
| --- | --- |
| `kind` | `null`（无模型，不产生检测）或 `yolo`（Ultralytics 权重） |
| `model_path` | 相对仓库根或绝对路径；相对路径由 `resolve_runtime_file` 解析 |
| `imgsz` | `0` = 自适应权重里训练时的尺寸；非 0 时按 stride 向上取整 |
| `device` | `auto`（默认）= 有 CUDA 用 `cuda:0`，否则 `cpu`；也可显式写 `cpu` / `cuda:0` / `0` |
| `half` | FP16 推理，仅在 CUDA 上生效 |
| `raw_mode` | `true` = 旁路 SOP，只交出全量检测结果，便于先核对标签 |

**类别名必须与训练导出模型一致。** 当前 `best.pt` 的 4 个类别：

| id | 名称 | 配置字段 |
| --- | --- | --- |
| 0 | `hand` | `hand_label` |
| 1 | `brush` | `brush_label` |
| 2 | `oil_station` | `tray_label` |
| 3 | `screw` | `screw_label` |

- `tray_label` 字段名沿用 `tray`，因为流水线里涂油盘一律以“盘体/取料参考区”
  语义处理；值填模型实际输出的 `oil_station`。
- 旧字段 `rod_label` → `screw_label`，`brush_head_label` → `brush_label`，
  读取时自动迁移。
- `brush_point_offset_x/y`：模型只输出刷具框、没有关键点时，用框内相对坐标
  估计刷头工作端（默认 `0.5` / `0.9`）。
- `cycle_seconds` 已随脚本演示检测器一并移除。

### 4.8 demo：示例视频

```json
{
  "loop": true,
  "fps_limit": 15,
  "videos": [
    {"name": "示例① 105708", "path": "data/sample_video/cam_6ca47a_20261027_105708.mp4"},
    {"name": "示例② 140911", "path": "data/sample_video/cam_6ca47a_20261027_140911.mp4"}
  ]
}
```

- 画面来源是视频文件，检测仍由训练好的模型完成，不再有脚本伪造的检测框；
- `name` 显示在监控页“画面源”下拉里，`path` 同样按仓库根解析；
- 示例回放**不写入训练录制**；
- `videos` 为空时下拉里只有“实时相机”。

## 5. ROI 坐标与标定

### 5.1 坐标定义

ROI 使用相对原始视频帧的归一化坐标（0~1），支持矩形和多边形。预览窗口缩放
不影响坐标。

### 5.2 现场标定步骤

1. 设置页 → “打开 ROI 标定”；
2. 打开相机 → 截取画面；
3. 依次选择“涂油盘区 / 手持操作区 / 刷涂区 / 排除区”，拖拽矩形；
4. 保存并应用，检测服务自动重载配置。

### 5.3 常见问题

- ROI 紧贴目标会导致刷头刚接触就出界：预留移动余量；
- 物料盒未排除会形成漏标负样本：务必配置 `exclude_rois`；
- 涂油盘 ROI 与检测盘体不一致时，优先相信检测盘体，短时丢失回退固定 ROI。
