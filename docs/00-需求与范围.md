# 00 需求与范围

对应《涂油工位视觉检测项目实现文档》第 1、13、15 节。

## 1. 背景

涂油机自动涂油后，工人从涂油盘取出一根丝杆，另一只手用红色长杆刷具
进行二次涂油。现场设备遮挡严重、涂油盘上下移动、人工双手并行操作，
原“四槽位持续定位”方案不稳定，因此本期只保留两个**现场判定点**：
确认一根丝杆被取出，以及这根丝杆完成人工二次涂油。

## 2. 第一阶段目标

1. 取料判定：手**空手**进入涂油盘、**带料**离开，才算取料完成；
2. 涂油判定：取料后手持丝杆，刷子靠近累计到 `brush_hold_s` 才算二次涂油完成；
3. 一个周期发 `PICK` 与 `MANUAL_OILING` 两类确认事件，完成后自动复位；
   另有一条异常事件 `OILING_MISSING`：取料后二次涂油没完成就来了下一次取料，
   或取料后超过 `oiling_timeout_s`（默认 10 秒）仍未完成，上一周期判 `NG`；
4. 提供监控、事件复核、训练录制和阈值调整 UI。

## 3. 范围与非目标

本期做：

- 三个区域：涂油盘区（`tray_roi` + `oil_station` 检测框）、工作追踪区
  （`work_roi`，跟踪范围）、涂油区（`oiling_roi`，本轮仅标定与显示）；
- 丝杆、手、刷头检测契约；
- 手/刷头 ByteTrack 跟踪、手-丝杆空间关联；
- 取料判定、涂油判定、作业周期复位；
- 事件保存、人工复核、训练视频录制。

本期不做：

- 不识别槽位，不绑定槽位，不做丝杆业务身份；
- 不做放料判定；不做槽位/丝杆业务身份；除漏涂 NG 外不做其他分级；
- 涂油区本轮不参与判定（预留给后续涂油范围约束）；
- 不判断机器自动涂油是否成功；
- 不检测最终存储盘及其状态；
- 不做模型训练，不承诺油脂附着量或涂层质量。

工作追踪区就是跟踪与判定的有效范围，区外目标完全不参与推理。

## 4. 现场难点

- 丝杆可能被手完全遮挡；
- 刷头小、运动快，检测框中心未必代表工作端；
- 手持丝杆会移动、旋转；
- 涂油盘随机构上下移动；
- 双手并行，可能出现多个候选；
- 视频丢帧、断流会破坏时序证据。

## 5. 技术路线

```text
视频解码 → 区域过滤（涂油盘区 + 工作追踪区）
        → 检测 screw / hand / brush_head (+ brush_rod / oil_tray)
        → 手/刷头 ByteTrack 跟踪
        → 手-丝杆关联（距离 + 交互关系，全局一对一）
        → 取料判定：空手进盘 → 带料离盘 → PICK/CONFIRMED
        → 作业周期 TASK-xxxxxx（视觉 ID 可更新）
        → 涂油判定：手持丝杆 + 刷子靠近累计 ≥ brush_hold_s → MANUAL_OILING/CONFIRMED
        → 周期复位，等待下一次取料
        → UI / 事件 / 关键帧与视频
```

## 6. 检测逻辑要点

### 取料

- 跟踪到一只手**空手**进入涂油盘区（`tray_roi` 并上模型检出的 `oil_station` 框）；
- 同一只手**带着丝杆离开**涂油盘区，且盘内停留 ≥ `pick_confirm_s`；
- 立即发出 `PICK/CONFIRMED`，不要求进入涂油区；
- 带料进盘又带料离盘、或空手离开，都不算取料。

### 二次涂油

- 取料之后手持丝杆，刷头工作端进入丝杆接触邻域（`brush_contact_distance`）；
- 累计靠近时长达到 `brush_hold_s`（默认 1.0s）即判完成；
- 刷子只短暂靠近、未接触，都不累计到完成。

## 7. 状态机

```text
WAITING_PICK ──PICK──> PICKED ──MANUAL_OILING──> OILED
       ▲                                           │
       └────────── 周期复位，等待下一次取料 ─────────┘
```

只对取料与二次涂油发 `CONFIRMED` 事件；唯一的异常判定是漏涂 `NG`
（`OILING_MISSING`，结果 `NEEDS_REVIEW`）。漏涂有两个触发点：下一次取料到
来，或取料后超过 `oiling_timeout_s`（默认 10 秒）仍未完成二次涂油。

## 8. UI 与事件

- 监控页：实时画面、三个区域（涂油盘区 / 工作追踪区 / 涂油区）、检测/跟踪框、
  周期阶段与刷子靠近进度、事件列表；
- 复核页：事件时间、任务 ID、事件类型、结果、人工复核；
- 设置页：取料/跟踪/涂油阈值与 ROI 标定；
- 事件使用视频时间戳，不以帧序号计算时长；
- 断流、丢帧、推理积压产生独立告警。

## 9. 验收指标

- 检测层：各类别 P/R/mAP，刷头小目标召回率；
- 跟踪层：ID Switch、轨迹中断率、手持关联成功率；
- 事件层：取料召回/误报、涂油召回/误报、完成判定准确率与时间偏差；
- 系统层：端到端结果、推理延迟、丢帧率、待确认比例、连续运行稳定性。

## 10. 待业务确认

1. 刷头需要覆盖丝杆哪些长度区间，是否要求全长覆盖？
2. 工人是否会在左手中转动丝杆，是否要求周向涂抹？
3. 刷头最短接触时长、有效移动距离、允许中断时间？
4. 取料后多久必须开始二次涂油，是否允许停顿或补涂？
5. 丝杆完全遮挡或暂时离开画面时如何处理？
6. 二次涂油完成即任务结束，还是还需确认丝杆离开操作区？
