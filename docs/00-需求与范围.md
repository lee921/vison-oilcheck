# 00 需求与范围

对应《涂油工位视觉检测项目实现文档》第 1、13、15 节。

## 1. 背景

涂油机自动涂油后，工人从涂油盘取出一根丝杆，左手持料，右手用红色长杆刷具
进行二次涂油。现场设备遮挡严重、涂油盘上下移动、人工双手并行操作，原“四槽位
持续定位”方案不稳定，因此本期改为**事件识别**：确认一根丝杆被取出，并跟踪
这根丝杆完成二次涂油。

## 2. 第一阶段目标

1. 检测丝杆是否随手从涂油盘离开，不能仅凭手离开涂油盘判定取料；
2. 取料后建立并跟踪业务任务，允许短时遮挡和姿态变化；
3. 检测刷头工作端是否接触当前手持丝杆，并判断是否存在有效刷涂运动；
4. 融合取料与刷涂证据，输出 `OK / NG / PROCESSING / PENDING_CONFIRMATION`；
5. 提供监控、事件复核、训练录制和阈值调整 UI。

## 3. 范围与非目标

本期做：

- 涂油盘参考区域、手持操作区、刷涂区与物料盒排除区；
- 丝杆、手、刷头（可选刷杆/涂油盘）检测契约；
- 短时跟踪、取料事件、手持任务、刷涂接触/运动/覆盖；
- 事件保存、人工复核、训练视频录制。

本期不做：

- 不识别具体取自哪个槽位，不建立四槽位绑定；
- 不要求四槽位持续可见，上方设备遮挡不再是核心前提；
- 不判断机器自动涂油是否成功；
- 不检测最终存储盘及其状态；
- 不做模型训练，不承诺油脂附着量或涂层质量。

物料盒区域完全不参与推理，必须配置为排除 ROI。

## 4. 现场难点

- 丝杆可能被手完全遮挡；
- 刷头小、运动快，检测框中心未必代表工作端；
- 手持丝杆会移动、旋转；
- 涂油盘随机构上下移动；
- 双手并行，可能出现多个候选；
- 视频丢帧、断流会破坏时序证据。

## 5. 技术路线

```text
视频解码 → ROI 裁剪/排除物料盒
        → 检测 screw / hand / brush_head (+ brush_rod / oil_tray)
        → 短时跟踪（视觉 Track ID）
        → 取料事件：手部交互 + 共同运动 + 离盘 + 持续关联
        → 业务任务 TASK-xxxxxx（视觉 ID 可更新）
        → 刷涂行为：刷头接触 + 丝杆局部轴向相对运动 + 覆盖区段
        → 任务状态机 → OK / NG / PROCESSING / PENDING_CONFIRMATION
        → UI / 事件 / 关键帧与视频
```

## 6. 检测逻辑要点

### 取料

- 取料前丝杆在涂油盘 ROI 内被检测到，建立候选；
- 手与丝杆空间接近/交叠，且连续帧呈共同位移；
- 丝杆主体离开涂油盘区域并进入手持操作区；
- 后续帧仍能在手附近关联到该丝杆，才确认取料；
- 多候选距离接近时不强制选最近，输出待确认。

### 二次涂油

- 以当前手持丝杆为中心，刷头工作端进入接触邻域；
- 将刷头投影到丝杆局部坐标系，分析轴向相对运动；
- 接触 + 有效相对运动 + 覆盖区段/时长达到阈值才判完成；
- 刷杆经过但未接触、刷头靠近但未运动，不累计进度。

## 7. 状态机

```text
WAITING_PICK → PICK_CANDIDATE → LEAVING_TRAY → PICK_CONFIRMED
            → HOLDING → BRUSH_CONTACT → BRUSHING → OILING_COMPLETED
任意阶段证据不足 → PENDING_CONFIRMATION
明确违反工艺且证据充分 → NG
```

## 8. UI 与事件

- 监控页：实时画面、四类 ROI、检测/跟踪框、任务状态、覆盖进度、事件列表；
- 复核页：事件时间、任务 ID、事件类型、结果、人工复核；
- 设置页：取料/跟踪/刷涂阈值与 ROI 标定；
- 事件使用视频时间戳，不以帧序号计算时长；
- 断流、丢帧、推理积压产生独立告警。

## 9. 验收指标

- 检测层：各类别 P/R/mAP，刷头小目标召回率；
- 跟踪层：ID Switch、轨迹中断率、手持关联成功率；
- 事件层：取料召回/误报、接触 Precision/Recall、完成判定准确率与时间偏差；
- 系统层：端到端结果、推理延迟、丢帧率、待确认比例、连续运行稳定性。

## 10. 待业务确认

1. 刷头需要覆盖丝杆哪些长度区间，是否要求全长覆盖？
2. 工人是否会在左手中转动丝杆，是否要求周向涂抹？
3. 刷头最短接触时长、有效移动距离、允许中断时间？
4. 取料后多久必须开始二次涂油，是否允许停顿或补涂？
5. 丝杆完全遮挡或暂时离开画面时如何处理？
6. 二次涂油完成即任务结束，还是还需确认丝杆离开操作区？
