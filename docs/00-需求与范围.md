# 00 需求与范围

本文件沉淀第一阶段需求，作为后续实现与验收的共同基线。实现状态见
[11-实施路线与风险.md](11-实施路线与风险.md)。

## 1. 背景

涂油机将丝杆逐根完成设备自动涂油后，员工从涂油盘/夹具位置取出丝杆，进行人工
二次涂抹油脂。设备一次装入 4 根丝杆，但逐根涂油；员工可能在第一根完成后即取出，
不必等待其余丝杆全部完成。因此系统必须按单根物料维护流程状态，不能只按整批设备
周期判断。

现场确认：**取料区物料盘连续移动，取料时也不停止**。因此系统跟踪机器涂油盘整体
位置，并按盘体局部几何实时计算 4 个槽位 ROI；槽位状态与逐根物料操作记录并行维护。

## 2. 第一阶段目标

1. **取料检测**：识别员工是否从机器涂油盘取出已完成设备涂油的丝杆。
2. **二次涂油检测**：结合手部、刷子、丝杆位置与相对运动，识别人工二次涂油动作。
3. **流程与 UI**：实时展示 4 个槽位状态、单根物料操作状态、事件与待复核项。
4. **数据采集**：录制训练视频，供另一个项目训练模型。

## 3. 范围与非目标

| 类别 | 内容 |
| --- | --- |
| 本阶段包含 | 取料事件识别；二次涂油动作识别；单根物料状态管理；实时 UI；异常记录与人工复核入口；训练视频录制 |
| 不包含 | 员工离岗；上料数量；设备启停；放料检测；油脂用量/覆盖质量检测；模型训练 |
| 重要边界 | 系统识别的是可从视频观察到的操作行为，不直接等同于油脂实际用量或涂层质量合格 |

## 4. 现场难点

- 取料区位于画面上方中部，手部会进入并遮挡丝杆。
- 丝杆外观相似、可能紧密排列，单帧检测框或通用跟踪 ID 不足以稳定代表某一根物料。
- 手部接触丝杆不代表取料完成；暂时遮挡也不能直接判定已取走。
- 二次涂油与普通拿取、调整位置可能相似，必须用连续视频验证可区分性。
- 员工可提前取第一根，动作需支持不同丝杆交错处理。

## 5. 技术路线

```text
目标检测（手/刷子/盘体/丝杆） + 盘体动态槽位 + 时序事件判断 + 逐根物料状态机
```

优先用可解释规则完成事件判定；若二次涂油无法由规则稳定区分，再引入时序动作
识别模型。模型训练在另一个项目中完成，本项目只定义检测结果契约并消费模型输出。

物料关联：

- 机器涂油盘整体位置由 `TrayTracker` 跟踪；
- 4 个槽位由 `slot_layout` 相对盘体局部几何动态计算，随盘体上下移动；
- 取料确认后建立 `Part-A`、`Part-B` 等逻辑物料操作记录，来源槽位写入事件证据。

## 6. 检测逻辑要点

### 取料

- 机器涂油盘 4 个槽位分别维护 `OCCUPIED / EMPTY / UNKNOWN`。
- 取料候选：手部进入 `OCCUPIED` 槽位邻域。
- 取料确认：手部交互后，槽位在清晰可见条件下稳定变为 `EMPTY`（OCCUPIED→EMPTY）。
- 证据不足：遮挡超时、盘体定位不可靠、身份关联冲突 → 待确认，不强行判定。

### 二次涂油

- 取料确认后建立逻辑操作记录（`Part-A`…）。
- 刷子接近被取走物料时进入 `OILING_CANDIDATE`，累计刷子相对物料的运动时长与位移。
- 满足现场标定规则后进入 `OILING_CONFIRMED`。
- 证据不足或身份冲突：`PENDING_CONFIRMATION` / `IDENTITY_UNCERTAIN`。

实现原则：

- 不以手部接触、刷子出现、单帧位置或预测轨迹单独作为完成依据。
- 机器盘状态与人工操作状态并行，机器继续处理其他槽位不阻塞人工操作。
- 视觉只能确认可观察动作是否发生，不能保证油量、覆盖范围或涂层质量。

## 7. 状态机

```text
槽位：UNKNOWN → OCCUPIED → EMPTY
              └── 遮挡/盘体不可靠超时 → UNKNOWN

操作：PICKED → OILING_CANDIDATE → OILING_CONFIRMED
                    │
                    ├─ 证据不足 → PENDING_CONFIRMATION
                    └─ 关联冲突 → IDENTITY_UNCERTAIN
```

每个槽位、每条人工操作独立维护状态，允许交错处理；遮挡/身份不确定时保留待确认，
不强行判定。

## 8. UI 与事件

第一阶段建设一个实时监控页 + 异常/待复核列表：

- 顶部状态栏：在线状态、工位、检测模式、槽位统计；
- 实时视频：机器涂油盘框、4 个动态槽位、手部/刷子轨迹、丝杆检测框；
- 槽位面板：4 个槽位的 `OCCUPIED / EMPTY / UNKNOWN`、可见性与变化原因；
- 人工操作列表：逻辑物料编号、来源槽位、取料/涂油状态、身份关联与原因；
- 事件列表：时间、类型、逻辑物料标识、结果、处理状态；
- 复核入口：人工标注“确认异常/误报/无法判断”。

事件字段至少包含：`event_id`、起止时间、`station_id`、`cycle_id`、`logical_part_id`、
`slot_index`、`event_type`、`result`、`evidence`、`review_result`；`evidence` 中记录
`operation_id`、`source_slot`、`pickup_status`、`identity_status` 与证据列表。

## 9. 验收指标

现场视频验证后确定目标值，分别报告取料与二次涂油：

| 指标 | 定义 |
| --- | --- |
| 取料事件召回率 | 真实取料中系统成功识别的比例 |
| 取料事件准确率 | 系统确认的取料中确实发生的比例 |
| 二次涂油事件召回率 | 真实涂油动作中系统成功识别的比例 |
| 二次涂油事件准确率 | 系统确认完成中确实执行规定动作的比例 |
| 待确认比例 | 因遮挡/证据不足进入待确认的事件比例 |
| 事件延迟 | 动作实际发生至 UI 显示确认结果的时间 |

不以单一目标检测 mAP 代替流程效果；先离线视频回放评估，再现场实时试运行。

## 10. 待业务确认

- “取料完成”“二次涂油完成”的可观察标准；
- 是否可能双手同时操作两根丝杆；
- 机器涂油盘是否只有上下平移，是否存在旋转/透视变化；
- 4 个槽位相对盘体的几何是否固定、是否允许跨位放置；
- 异常处置方式（仅记录/待复核/声光报警/继电器）；
- 现场节拍与可接受延迟；
- 录制保留周期与磁盘配额；
- 是否需要 Web 端或多机集中管理。
