## 3. 外部模型项目契约

训练项目交付物至少包括：

1. **权重文件**（`.pt` / `.onnx` 等）与版本号；
2. **类别定义**：手部、丝杆（可扩展工具/油脂容器）；
3. **输入规范**：图像尺寸、颜色顺序、归一化方式；
4. **输出规范**：框坐标（原始帧像素）、置信度、类别；
5. **评估报告**：在取料/涂油关键 ROI 上的召回率、误检率、遮挡场景表现；
6. **推理速度**：目标硬件上的单帧耗时。

本项目接入只需：

- 把权重放到可访问路径；
- 设置 `detector.kind=yolo`、`model_path`、标签名、置信度；
- 如需局部高分辨率推理，在 `YoloDetector.detect()` 内裁剪；
- 用本项目录制的视频做离线回放，确认事件指标。

## 4. 风险与待确认事项

| 风险 | 影响 | 当前应对 | 待确认 |
| --- | --- | --- | --- |
| 手部遮挡丝杆 | 取料状态/任务身份不确定 | 共同运动证据、遮挡超时待确认、业务层重关联 | 现场遮挡时长分布；阈值是否足够 |
| 涂油盘连续移动 | 固定坐标失效 | `TrayTracker` 跟踪盘体，丢失时回退固定 ROI | 现场速度、遮挡下的盘体定位稳定性 |
| 丝杆外观相似、排列紧密 | 单根 ID 切换 | 视觉 Track ID 与 `TASK-xxxxxx` 分离；多候选转待确认 | 交叉/遮挡场景是否需要编码器信号 |
| 二次涂油与普通调整相似 | 漏报/误报 | 刷头工作端接触 + 丝杆局部轴向运动 + 覆盖区段 | 正负样本是否可分；是否需要动作分类模型 |
| 单张截图不足以判定 | 阈值无法确定 | 训练录制 + 离线回放 | 必须采集连续视频 |
| 动作识别 ≠ 涂油质量 | 不能保证油量/覆盖 | UI/文档明确边界 | 若需质量检测，另行评估成像 |
| 模型小目标漏检 | 取料/涂油证据缺失 | ROI 局部推理预留 | 现场分辨率与镜头 |
| 录制占用磁盘/CPU | 工控机压力 | 有界队列、分段、手动开关 | 磁盘容量与保留周期 |
| 事件片段缺失 | 复核效率 | 预留字段与文档方案 | 下一阶段实现 |
| 多相机/多工位 | ROI 与资源竞争 | 每工位独立执行器 | 现场相机数量与算力 |

## 5. 下一阶段建议顺序

1. **P0 数据采集**：用训练录制页采集覆盖场景的视频，人工标注；
2. **模型接入**：外部项目交付权重后，启用 `yolo` 适配器，先离线回放；
3. **阈值标定**：按 `reason` 分布调整 `pipeline` 参数，形成基线报告；
4. **事件片段**：实现事件前后 N 秒片段，提升复核效率；
5. **ROI 工具**：在监控页截图/拖拽标定，减少手工换算错误；
6. **现场试运行**：小范围、可回退，按班次统计误报/漏报/待确认/延迟；
7. **动作模型（可选）**：若规则区分度不足，训练短视频分类模型，替换涂油证据层；
8. **交付工程化**：打包、开机自启、日志归档、磁盘清理策略。

## 6. 需要业务方确认的问题

- “取料完成”的准确定义：手离开工位即可，还是丝杆完全离开取料区？
- “二次涂油完成”的可观察标准：次数、时长、工具、油脂容器、动作幅度？
- 员工是否可能双手同时操作两根丝杆？
- 4 个取料位是否固定，是否允许跨位放置？
- 异常处置方式：只记录/待复核，还是需要声光报警/继电器输出？
- 现场节拍与可接受的事件延迟。
- 录制保留周期与磁盘配额。
- 是否需要 Web 端或多机集中管理。
