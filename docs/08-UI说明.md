# 08 UI 说明

对应实现文档第 11 节。UI 结构尽量保持原样，首页的检测语义改为作业周期：
取料完成 → 人工二次涂油完成。

## 1. 页面结构

```text
主窗口
├─ 实时监控
├─ 事件复核
├─ 训练录制
├─ 设备管理
├─ 设置
└─ 日志
```

## 2. 实时监控页

### 2.1 顶部状态栏

- 工位选择；
- 相机状态（预览中/离线/示例回放）；
- 画面源（实时相机 / 示例视频）；
- 检测模式（无模型/模型）；
- 检测耗时、目标数与各类别计数；
- 录制状态；
- 显示追踪 ID（默认勾选）；
- 开始/停止、重置状态、截图。

### 2.2 视频区

绘制：

- 工作追踪区（蓝）；
- 涂油区（绿色虚线，本轮仅显示）；
- 检测到的涂油盘框（橙色，`oil_station`）与丝杆/手部/刷头检测框；
- 刷头关键点（小圆点）；
- 跟踪 ID 徽标（勾选“显示追踪 ID”时），见下；
- 顶部横幅：工位、相机状态、模式、盘体可靠性、当前任务 ID。

**检测框与跟踪 ID 是两套信息，各自可读：**

| 元素 | 样式 | 含义 |
| --- | --- | --- |
| 检测框标签 | 彩色底 + 黑字（`screw 0.88`） | 模型在这一帧看到了什么、置信度多少 |
| 跟踪 ID 徽标 | 深色底 + 彩色字，贴在框右侧 | 管线正在跟踪谁 |

徽标内容是视觉轨迹 ID：手 `#100004`、刷头 `#200001`，前缀区分对象类型。

只有中心落在工作追踪区或涂油盘参考区内的目标才会被跟踪，因此画面上的每个
ID 都对应一个“在跟踪范围内的目标”；区外目标连框带 ID 都不出现。

丢失中的轨迹（`observed=False`）没有当帧检测框，用虚线框画出预测位置，
ID 后缀加 `?`，不会和实测目标混淆。

开关放在顶部工具条，默认打开；关闭后只画检测框。

### 2.3 检测区域与跟踪

两张卡片：

| 卡片 | 展示 |
| --- | --- |
| 工作追踪区 | 区内跟踪的丝杆数、手部数、刷具数 |
| 涂油区 | 是否已标定；说明本轮仅显示、预留涂油范围约束 |

涂油盘区不在监控页展示——它是判定内部的参考区（`tray_roi` 与模型检出的
`oil_station` 框取并集），不是操作对象，仍可在标定窗口查看与调整。

### 2.4 任务区

最近 4 条任务卡片：

- 任务 ID 与当前阶段（等待取料 / 已取料 / 涂油完成）；
- 最终结果（进行中/已完成/`NG`），按结果着色（`NG` 为红色）；
- 手部轨迹与「刷子靠近累计 / 阈值」；
- 进度条：`brush_hold_s / brush_hold_target_s` 的百分比；
- 悬浮提示：丝杆/手/刷头 Track ID、刷子靠近累计、证据列表、时间线。

### 2.5 事件列表

列：时间、事件、任务、结果/复核。非 `CONFIRMED` 事件用黄色高亮
（漏涂 `OILING_MISSING` 就是 `NEEDS_REVIEW`，会高亮并进入待复核）；
双击跳转复核页。

## 3. 事件复核页

- 筛选：待复核/全部/已复核；
- 列：时间、工位、任务、事件、结果、复核、片段；
- 操作：确认异常、误报、无法判断，可填写备注；
- 片段入口保留，第一版未生成事件片段时提示使用训练录制视频。

## 4. 训练录制页

按相机启动/停止分段录制，显示已写帧数、分段路径、错误；支持删除历史分段。
示例回放的帧绝不写入训练录制。

## 5. 设置页

分为：

1. **应用设置**：布局、UI 帧率、解码帧率、离线超时、截图/日志目录；
2. **ROI 标定**：涂油盘区、工作追踪区、涂油区；标定窗口顶部“画面源”可在
   实时相机与 `demo.videos` 登记的示例视频之间切换，选择示例视频后拖动
   “视频位置”挑选一帧即可绘制 ROI，不依赖相机；
3. **取料事件与二次涂油判定**：手-丝杆接近距离、盘内停留确认时长、
   刷头接触距离、刷子靠近判完成时长、手持丢失超时；
4. **涂油盘定位**：关联距离、漏检保留、最低置信度；
5. **手与丝杆关联**：最大关联距离、手持推断距离；
6. **高级**：手持位置预测保持、手/刷头跟踪后端；
7. **手部 / 刷头跟踪**：最大关联距离、漏检保留、最少命中帧数、
   最大同时任务数、完成后保留时长；
8. **训练视频录制**：目录、帧率、分段时长、编码。

保存后写入 `oilcheck.json` 并通知服务重载。

## 6. 刷新机制

- 视频按 `ui_fps` 刷新；
- 状态/任务/事件每 200ms 刷新；
- 事件表按 `EventStore.version` 判断是否重建；
- 所有跨线程回调通过 `UiInvoker` 回到 Qt 主线程。

## 7. 示例视频回放

顶部“画面源”下拉由 `config/oilcheck.json` 的 `demo.videos` 生成：

| 选项 | 行为 |
| --- | --- |
| 实时相机 | 走海康相机链路，按钮为“开始 / 停止” |
| 示例① / 示例② | 回放 `data/sample_video` 下的真实录像 |

- 画面来自视频文件，检测结果来自训练好的模型，不再有脚本伪造的检测框；
- 回放期间相机启停按钮显示“示例回放中”并禁用，切回实时相机即可恢复；
- 顶部“速率”下拉（`0.5× / 1× / 2×`）只在示例回放时出现：0.5× 用于现场逐帧
  核对，1× 原速。速率只影响播放快慢，判定阈值按视频媒体时间计时，结果不变；
- 画面下方信息条显示 `画面 宽×高 · 示例回放 名称 · 第 N/M 帧 · 速率 · 进度%`
  （原速时省略速率）；
- 画面左上角横幅在回放时额外显示当前**帧号**（`第 N/M 帧`，1 基，与 ROI
  标定窗口的帧号口径一致），方便对照原始录像定位问题；**实时相机不显示帧号**；
- 示例回放**不写入训练录制**；
- 画面上只显示**工作追踪区/涂油盘区内**的检测框（与跟踪范围一致），
  外加当前正在判定的那根丝杆——手把它举到区外时也保持可见；
- 画面上的检测框覆盖模型输出的全部类别，配色按配置里的类别名分配，
  模型后续新增的类别也会自动取调色板颜色画出来。

## 8. 界面扩展点

- 多任务队列（关闭 `single_active_task`）；
- 事件前后视频片段；
- 关键帧缩略图与轨迹回放；
- 涂油区参与判定后的范围约束可视化。
