# 08 UI 说明

实现：`ui/main_window.py`、`ui/pages/`、`ui/widgets/oilcheck_video.py`。
界面为 PySide6 + QFluentWidgets 桌面端，全屏运行，左侧导航切换页面。

## 1. 页面结构

| 导航 | 页面 | 作用 |
| --- | --- | --- |
| 实时监控 | `MonitorPage` | 视频、ROI、检测框、物料状态、最近事件 |
| 事件复核 | `ReviewPage` | 筛选事件、查看证据、人工标注结果 |
| 训练录制 | `RecordingPage` | 控制录制、查看分段与存储位置 |
| 设备 | `DevicePage` | 相机增删改、连接测试 |
| 设置 | `SettingsPage` | 应用参数、判定阈值、录制参数 |
| 日志 | `LogsPage` | 运行日志查看 |

## 2. 实时监控页

### 2.1 顶部状态栏

| 控件 | 含义 |
| --- | --- |
| 工位下拉框 | 选择 `oilcheck.json` 中启用的工位 |
| 相机状态 | 未连接/连接中/已连接/预览中/停止中/错误/相机缺失 |
| 检测模式 | 无模型（待接入）/ 演示模式 / 模型检测 |
| 检测耗时 | 最近一帧的 `processing_ms` 与目标数 |
| 录制状态 | 关闭，或“录制中 mm:ss · N帧” |
| 开始/停止 | 启动或停止该工位相机 |
| 演示模式 | 运行时把检测器切到 `simulated`，不写配置 |
| 重置状态 | 复位该工位的物料状态机 |
| 截图 | 保存当前帧，用于 ROI 标定 |

录制控制统一放在“训练录制”页，监控页只显示录制状态，避免误操作。

状态色：

- 相机在线：绿色；离线/错误：红色；
- 演示模式：橙色（提醒不是现场结果）；无模型：灰色；模型检测：绿色；
- 录制中：红色。

### 2.2 视频区

- 保持原始宽高比，居中显示，黑底填充。
- 叠加层：
  - 机器涂油盘：黄色虚线框；
  - 4 个动态槽位：随盘体移动；`OCCUPIED` 绿色、`EMPTY` 灰色、`UNKNOWN` 琥珀，
    标签同时显示占用状态；
  - 手部轨迹：橙色框，标签 `hand#轨迹ID`；
  - 刷子轨迹：粉色框，标签 `brush#轨迹ID`；
  - 丝杆检测：绿色框；
  - 其他类别：蓝色。
- 左上角横幅：工位名 · 相机状态 · 检测模式 · 盘体可靠/不可靠。
- 无画面时显示“等待视频帧”。

### 2.3 槽位状态区

按 `slot_layout` 显示槽位卡片（默认 4 张）：

- 槽位名称与占用状态色块：`OCCUPIED / EMPTY / UNKNOWN`；
- 可见性：`VISIBLE / OCCLUDED / UNRELIABLE`；
- 最近状态变化原因（稳定有料、稳定空槽、遮挡超时、盘体不可靠等）；
- 悬停查看最近变化时间、置信度与原始 reason。

### 2.4 人工操作区

预置 4 张操作卡片，按取料时间顺序填充：

- 逻辑物料编号（`Part-A`、`Part-B`…）与来源槽位；
- 操作记录 ID；
- 状态色块：`PICKED / OILING_CANDIDATE / PENDING_CONFIRMATION /
  IDENTITY_UNCERTAIN / OILING_CONFIRMED`；
- 取料状态与身份关联状态；
- 悬停查看 reason 与完整证据列表。

状态颜色：

| 状态 | 颜色 |
| --- | --- |
| PICKED | 蓝 |
| OILING_CANDIDATE | 琥珀 |
| PENDING_CONFIRMATION | 红 |
| IDENTITY_UNCERTAIN | 紫 |
| OILING_CONFIRMED | 绿 |

### 2.5 事件列表

最近 20 条当前工位事件，列：时间、事件、物料、结果（已复核显示复核结果）。
非 `CONFIRMED` 事件用黄色文字提示。双击某行跳转复核页并选中该事件。

## 3. 事件复核页

- 筛选：待复核 / 全部 / 已复核；
- 统计：事件总数、待复核数、未确认数；
- 表格：时间、工位、物料、事件、结果、复核、片段；
- 操作：
  - 打开视频片段：第一版无事件片段，会提示使用训练录制；
  - 确认异常 / 误报 / 无法判断：写入复核记录；
  - 备注输入框可选；
- 自动刷新：事件版本变化时刷新，不打断当前选择。

监控页事件列表下方还有“清空事件”按钮，二次确认后删除本机事件与复核记录；
训练视频、配置和日志不受影响。详见
[06-事件记录与人工复核.md](06-事件记录与人工复核.md)。

## 4. 训练录制页

左右分栏：

- 左侧：实时/录像播放器
  - 默认显示当前相机实时画面；
  - 点击“开始录制”会自动启动相机预览、切回实时，等相机就绪后再开始录制；
  - 播放录像时显示“录像：文件名”；
  - “实时画面”按钮从回放切回实时；
  - 停止预览或相机断开后立即清空画面并提示未预览，不会保留最后一帧；
- 右侧：已录制视频列表
  - 列：开始时间、时长、帧数、文件名（悬停查看相机/工位/丢帧/完整路径）；
  - 双击某段在左侧播放；
  - 双击播放结束后再次双击可重新播放；
  - 每行左侧勾选框选择视频，可“全选”，点击“删除勾选”二次确认后删除
    视频、元数据与 manifest 条目；正在录制的分段不允许删除；
- 顶部：相机下拉框、录制状态（已写帧/丢帧/当前分段）、存储目录；
- “预览/停止预览”：单独启动或停止相机预览，不启动录制；正在录制时禁止停止预览；
- 开始/停止录制、打开录制目录、刷新分段；
- 说明文字明确：录制原始画面（不带检测框），供外部训练使用。

## 5. 设置页

分六组：

1. 应用设置：布局（旧字段）、UI 帧率、解码帧率、离线超时、截图/日志目录；
2. ROI 标定：打开相机、截取画面、拖拽绘制盘体区/二次涂油区，保存并应用；
3. 取料与二次涂油判定：槽位有料/空置确认、遮挡转未知、取料中止/遮挡超时、
   取料证据窗口、刷子最短时长/最大间隙/最小相对位移、刷子-物料距离、
   身份关联超时、事件冷却；
4. 机器涂油盘跟踪：盘体关联距离、短时漏检保留、最低置信度；
5. 手部 / 刷子跟踪：各自关联距离、漏检保留、最少命中帧数、最大同时操作数、
   完成后保留时长；
6. 训练视频录制：目录、帧率、分段时长、FourCC、自动开始。

ROI 标定对话框：

- 自动打开所选工位相机，显示实时画面和原始分辨率；
- “截取画面”冻结当前帧后，在画面上拖拽矩形；拖到画面外会自动裁剪到画面边缘；
- “设置盘体区/设置涂油区”切换当前绘制目标，已有 ROI 会叠加显示并标注像素尺寸；
- “清除当前区域”删除当前目标已画的 ROI；
- “保存并应用”写入 `oilcheck.json` 并重新加载检测服务；盘体区与旧 `pick_roi`
  一致时会同步 `tray_roi`；
- 4 个槽位的局部几何 `slot_layout` 需在 `oilcheck.json` 中配置；
- 未启用的工位也会出现在下拉框中（标注“未启用”），可预先标定；
- 保存、取消或直接关闭窗口时，都会停止该工位的相机预览。

“保存全部”同时写 `app.json` 与 `oilcheck.json`，随后：

- 相机管理器更新应用参数；
- 检测服务重建工位运行时（阈值立即生效）；
- 录制器的改动在下次开始录制时生效（正在录制的不打断）。

## 6. 刷新机制

| 内容 | 周期 | 来源 |
| --- | --- | --- |
| 视频帧 | `1000 / app.ui_fps` | 相机 `FrameBuffer` 最新帧 |
| 状态/物料/录制/事件 | 200 ms | `OilCheckService` 快照、`EventStore.version` |
| 复核表 | 1 s（版本变化才重建） | `EventStore` |
| 录制状态/分段 | 1 s / 5 s | 录制器状态、分段元数据扫描 |

UI 不做检测、不写事件、不阻塞在相机 SDK 调用上；耗时操作（启动/停止相机、
截图、复核写盘）通过线程池/服务接口完成。

## 7. 演示模式

用途：无模型时验证 UI、状态机、事件、复核、录制链路。

- 在监控页点击“演示模式”；
- 服务把该工位检测器临时替换为 `SimulatedDetector`；
- 顶部模式显示橙色“演示模式”；
- 取消勾选恢复 `oilcheck.json` 中的检测器；
- 不写配置文件，重启后自动恢复。

演示数据会按周期生成取料、涂油、遮挡、待确认等事件，便于走通复核流程。
**禁止把演示事件当作现场结果。**

## 8. 界面扩展点

- ROI 标定已支持矩形拖拽；后续可扩展多边形绘制、缩放/平移与十字准星；
- 增加多工位总览：缩略图 + 每工位状态灯；
- 增加事件片段播放器：嵌入 Qt Multimedia 或调用系统播放器；
- 增加班次统计/导出：读取 `EventStore`；
- 若后续需要 Web 端，可复用 `OilCheckService` 快照接口，增加 HTTP/WebSocket
  推送层，而不改状态机与检测器。
