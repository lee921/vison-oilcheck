# 08 UI 说明

对应实现文档第 11 节。UI 结构尽量保持原样，首页的检测语义改为单根丝杆任务。

## 1. 页面结构

```text
主窗口
├─ 实时监控
├─ 事件复核
├─ 训练录制
├─ 设备管理
├─ 设置
└─ 日志
```

## 2. 实时监控页

### 2.1 顶部状态栏

- 工位选择；
- 相机状态（预览中/离线/示例回放）；
- 画面源（实时相机 / 示例视频）；
- 检测模式（无模型/模型）；
- 检测耗时、目标数、任务数（进行中/OK）、候选数；
- 录制状态；
- 开始/停止、重置状态、截图。

### 2.2 视频区

绘制：

- 涂油盘区（黄）、手持操作区（蓝）、刷涂区（红）、排除区（灰虚线）；
- 检测到的涂油盘框（橙色虚线，可靠/预测）；
- 丝杆/手部/刷头跟踪框及 Track ID；
- 刷头关键点（小圆点）；
- 顶部横幅：工位、相机状态、模式、盘体可靠性、当前任务 ID。

### 2.3 检测区域与跟踪

四张卡片保持原槽位卡片的位置与样式：

| 卡片 | 展示 |
| --- | --- |
| 涂油盘参考区 | 是否检测到盘体、可靠/预测、运动状态、置信度 |
| 手持操作区 | 手部轨迹数、丝杆轨迹数 |
| 刷涂区 | 刷头轨迹数 |
| 物料盒排除区 | 已配置排除区域数量 |

### 2.4 任务区

最近 4 条任务卡片：

- 任务 ID 与当前阶段；
- 最终结果（进行中/OK/NG/待确认），按结果着色；
- 取料、手持、刷涂三个子状态；
- 覆盖进度条（`coverage`）；
- 悬浮提示：丝杆/手/刷头 Track ID、有效刷涂时长、相对运动量、
  覆盖区段、证据列表、时间线。

### 2.5 事件列表

列：时间、事件、任务、结果/复核。非 `CONFIRMED` 事件用黄色高亮；
双击跳转复核页。

## 3. 事件复核页

- 筛选：待复核/全部/已复核；
- 列：时间、工位、任务、事件、结果、复核、片段；
- 操作：确认异常、误报、无法判断，可填写备注；
- 片段入口保留，第一版未生成事件片段时提示使用训练录制视频。

## 4. 训练录制页

按相机启动/停止分段录制，显示已写帧数、分段路径、错误；支持删除历史分段。
示例回放的帧绝不写入训练录制。

## 5. 设置页

分为：

1. **应用设置**：布局、UI 帧率、解码帧率、离线超时、截图/日志目录；
2. **ROI 标定**：涂油盘区、手持操作区、刷涂区、排除区；
3. **取料事件与二次涂油判定**：接近距离、共同运动时长、确认时长、
   遮挡超时、刷头接触距离、最短刷动时长、覆盖比例等；
4. **涂油盘定位**：关联距离、漏检保留、最低置信度；
5. **丝杆/手部/刷头跟踪**：关联距离、漏检保留、最少命中帧数、任务数；
6. **训练视频录制**：目录、帧率、分段时长、编码。

保存后写入 `oilcheck.json` 并通知服务重载。

## 6. 刷新机制

- 视频按 `ui_fps` 刷新；
- 状态/任务/事件每 200ms 刷新；
- 事件表按 `EventStore.version` 判断是否重建；
- 所有跨线程回调通过 `UiInvoker` 回到 Qt 主线程。

## 7. 示例视频回放

顶部“画面源”下拉由 `config/oilcheck.json` 的 `demo.videos` 生成：

| 选项 | 行为 |
| --- | --- |
| 实时相机 | 走海康相机链路，按钮为“开始 / 停止” |
| 示例① / 示例② | 回放 `data/sample_video` 下的真实录像 |

- 画面来自视频文件，检测结果来自训练好的模型，不再有脚本伪造的检测框；
- 回放期间相机启停按钮显示“示例回放中”并禁用，切回实时相机即可恢复；
- 画面下方信息条显示 `画面 宽×高 · 示例回放 名称 · 进度%`；
- 示例回放**不写入训练录制**；
- 画面上的检测框覆盖模型输出的全部类别，配色按配置里的类别名分配，
  模型后续新增的类别也会自动取调色板颜色画出来。

## 8. 界面扩展点

- 多任务队列（关闭 `single_active_task`）；
- 事件前后视频片段；
- 关键帧缩略图与轨迹回放；
- 覆盖区段可视化（在丝杆上绘制分段进度）。
