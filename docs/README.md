## 版本边界

当前版本为 **V2.4（简化判定版）**：

- 已完成：UI、涂油盘区/工作追踪区/涂油区标定、手/刷头 ByteTrack 跟踪、
  手-丝杆逐帧空间关联、取料判定（空手进盘 → 带料离盘）、
  人工二次涂油判定（刷子靠近累计）、作业周期复位、
  事件记录/复核、训练视频录制、示例视频回放。
- 正常生产只产生 `PICK` 与 `MANUAL_OILING` 两类 `CONFIRMED` 事件；漏涂时
  额外产生 `OILING_MISSING`（`NEEDS_REVIEW`），周期结果 `NG`。漏涂由下一次
  取料或 `oiling_timeout_s`（默认 10 秒）超时触发。
- 未完成：真实模型推理（`yolo` 适配器仅提供契约与骨架）、事件前后视频片段、
  涂油区范围约束、跨重启的完整业务恢复。
- 模型训练在另一个项目中完成，本项目只定义并消费检测结果契约。
