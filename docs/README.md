## 版本边界

当前版本为 **V1.0 框架版**：

- 已完成：UI、机器涂油盘/4 动态槽位、手部/刷子跟踪、逐根物料取料与二次涂油状态机、
  事件记录/复核、训练视频录制、演示模式、设置页 ROI 标定。
- 未完成：真实模型推理（`yolo` 适配器仅有骨架）、事件前后视频片段、
  盘体旋转/透视变化下的关键点几何。
- 模型训练在另一个项目中完成，本项目只定义并消费检测结果契约。
