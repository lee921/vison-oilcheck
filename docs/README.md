## 版本边界

当前版本为 **V2.0（事件识别版）**：

- 已完成：UI、涂油盘/手持/刷涂/排除四类 ROI、丝杆/手/刷头跟踪、
  取料事件证据链、业务任务与视觉 ID 分离、刷头接触/轴向运动/覆盖判定、
  事件记录/复核、训练视频录制、演示模式、设置页与 ROI 标定。
- 未完成：真实模型推理（`yolo` 适配器仅提供契约与骨架）、事件前后视频片段、
  周向覆盖与油脂附着量判定。
- 模型训练在另一个项目中完成，本项目只定义并消费检测结果契约。
- 不识别槽位、不绑定槽位；涂油盘只作为取料参考区域。
