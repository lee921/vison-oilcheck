# 04 视觉检测管线

## 1. 职责边界

检测管线解决三个问题：

1. **单帧感知**：这一帧里手部、刷子、机器涂油盘、丝杆在哪里（`detector.py`）。
2. **跨帧跟踪**：手部/刷子轨迹、盘体位置与盘内 4 个槽位的动态 ROI（`tracker.py`）。
3. **时序判定**：槽位三态、取料事件、逐根物料二次涂油状态（`pipeline.py`）。

模型训练不在本项目。本项目定义稳定的检测契约，外部训练项目只需产出符合契约的
模型或推理结果。

## 2. 检测结果契约

```python
FrameDetections(
    ts=1712345678.123,
    frame_size=(2560, 1440),
    detections=(
        Detection(label="hand",  confidence=0.90, box=BBox(...)),
        Detection(label="brush", confidence=0.87, box=BBox(...)),
        Detection(label="tray",  confidence=0.92, box=BBox(...)),
        Detection(label="rod",   confidence=0.90, box=BBox(...)),  # 丝杆
    ),
    source="yolo",
)
```

约定：

- 坐标是**原始帧像素**，左上原点；服务层不做缩放换算。
- 标签名由 `oilcheck.json` 的 `detector.hand_label` / `rod_label` /
  `brush_label` / `tray_label` 指定。
- 检测器只负责“这一帧里有什么”，不做跨帧判断；`track_id` 可由模型提供，但
  当前跟踪器自行维护稳定的内部 ID。
- 检测器在单个工位执行器线程内串行调用，无需自行加锁。

## 3. 检测类别

| 类别 | 配置字段 | 用途 | 必要性 |
| --- | --- | --- | --- |
| `hand` | `hand_label` | 手部位置、接近槽位、持握关联 | 必需 |
| `brush` | `brush_label` | 刷子位置、相对丝杆运动 | 必需 |
| `tray` | `tray_label` | 机器涂油盘位置、4 槽位动态 ROI | 必需 |
| `rod` | `rod_label` | 槽位占用、被取走的丝杆 | 强烈建议 |

## 4. 盘体与动态槽位

`app/oilcheck/tracker.py` 的 `TrayTracker` 对 `tray` 检测做单目标跟踪：

```text
每帧 tray 检测
  → 与预测框关联（中心距离 / IoU）
  → 命中：更新框、速度、置信度，matched=True
  → 未命中：保留 tray_max_missing_s 内预测框，reliable=False
  → 超时：清空框，所有槽位进入 UNRELIABLE
```

槽位几何由 `station.slot_layout` 定义，每个槽位是**相对盘体框的局部归一化矩形**：

```text
P_slot_i(t) = T_tray(t) · P_slot_i_local
```

`pixel_bbox(tray_box)` 在每帧把局部矩形映射到原图像素坐标，因此盘体上下移动时
槽位 ROI 自动跟随，不需要重新标定绝对位置。若现场盘体存在旋转或透视变化，应把
`slot_layout` 扩展为旋转框/关键点，而不是继续使用轴对齐框。

## 5. 槽位占用状态

每个槽位独立维护 `OCCUPIED / EMPTY / UNKNOWN`：

| 本帧证据 | 处理 |
| --- | --- |
| 槽位内稳定检测到 `rod` | 连续 `slot_occupied_confirm_s` 后 → `OCCUPIED` |
| 槽位清晰可见、无 `rod` | 连续 `slot_empty_confirm_s` 后 → `EMPTY` |
| 手部覆盖槽位且无丝杆证据 | 保持原状态；超时后 → `UNKNOWN` |
| 手部覆盖但 `rod` 仍可见 | 保持/确认 `OCCUPIED`，不因遮挡触发待确认 |
| 盘体缺失或置信度不足 | `visibility=UNRELIABLE`，暂停状态切换 |
| 遮挡/定位失效超过 `slot_occlusion_unknown_s` | → `UNKNOWN` |

关键约束：

- **单帧没有丝杆不等于空槽**；必须连续可见空置达到 `slot_empty_confirm_s`。
- `UNKNOWN` 不会因为“没看到”自动变成 `EMPTY`；只有恢复可见并满足空置时长才切换。
- 盘体定位不可靠时，旧 ROI 不用于判断物料离盘。

## 6. 手部与刷子跟踪

`ObjectTracker` 是通用多目标跟踪器：

- 贪心关联“预测框 + 中心距离/IoU”；
- 速度平滑，适应连续移动；
- 短时漏检保留 `*_max_missing_s`；
- **预测位置不作为交互或涂油证据**，只有本帧真实观测到的手/刷子才参与判定。

分别创建手部与刷子两个实例：

| 参数 | 作用 |
| --- | --- |
| `hand_track_max_distance` / `brush_track_max_distance` | 相邻帧关联距离 |
| `hand_track_max_missing_s` / `brush_track_max_missing_s` | 短时漏检保留 |
| `hand_track_min_hits` / `brush_track_min_hits` | 新轨迹确认帧数 |

## 7. 取料证据

取料确认不是“槽位变空”单条件，而是：

```text
手部进入 OCCUPIED 槽位邻域
  + 手部/槽位交互持续
  + 槽位在可见条件下稳定变为 EMPTY（pick_window_s 内仍有手部交互）
  → 建立逻辑物料，PICK/CONFIRMED
```

- 手部接近但丝杆仍在原位：超过 `pick_abort_s` 后取消取料候选。
- 槽位被手遮挡、超过 `occlusion_timeout_s` 仍无法确认：建立 `PENDING` 操作并
  发出 `PICK/NEEDS_REVIEW`；随后若槽位清晰变空，补发 `PICK/CONFIRMED`。
- 槽位无手部交互直接变空：仅更新槽位状态，不建立人工操作记录。

## 8. 二次涂油证据

每个操作维护“刷子相对物料”的运动证据：

```text
刷子与物料中心距离 ≤ brush_part_distance
  → 进入 OILING_CANDIDATE
  → 累计相对运动时长（帧间隙 > brush_max_gap_s 则重新累计）
  → 累计刷子相对物料的中心位移
  → 时长 ≥ brush_min_duration_s 且位移 ≥ brush_min_motion
  → MANUAL_OILING/CONFIRMED
```

- 刷子静止或只是经过：不确认，证据不足时输出 `PENDING_CONFIRMATION` 并发出
  `MANUAL_OILING/NEEDS_REVIEW`。
- `brush_require_hand=true` 时还要求关联手部本帧可见且靠近物料。
- 同一刷子同时接近多根物料、或同一物料出现多个刷子轨迹时，关联不确定，
  操作进入 `IDENTITY_UNCERTAIN`，不把钱/证据强行分配给某一根。

## 9. 服务层调度

`OilCheckService._poll_station()`：

1. 读取相机最新帧，`frame.ts <= last_frame_ts` 时跳过（去重）。
2. 若该相机在录制，提交帧给录制器。
3. 若工位执行器空闲，提交 `(bgr, ts)`；忙则丢帧。
4. 工作线程中：
   ```text
   detector.detect(bgr, ts) → FrameDetections
   pipeline.process(detections) → StationSnapshot
   ```
5. 快照包含槽位、盘体、手/刷轨迹与人工操作列表，UI 只读取快照。

## 10. 接入外部训练模型

### 10.1 模型要求

- 至少四个类别：`hand`、`brush`、`tray`、`rod`（或与配置标签一致）。
- 输入 BGR 图像；输出原始帧像素坐标。
- 小目标漏检时，建议在盘体/取料区做局部高分辨率推理后映射回全帧。

### 10.2 启用步骤

1. `uv add ultralytics`
2. 权重放到可访问路径，例如 `models/hand_brush_tray_rod.pt`。
3. 修改 `oilcheck.json`：
   ```json
   "detector": {
     "kind": "yolo",
     "model_path": "models/hand_brush_tray_rod.pt",
     "confidence": 0.5,
     "hand_label": "hand",
     "rod_label": "rod",
     "brush_label": "brush",
     "tray_label": "tray"
   }
   ```
4. 重启或保存设置页触发服务重载。
5. 用现场视频离线回放验证阈值后，再上现场运行。

### 10.3 离线回放

`tests/test_pipeline.py` 演示了构造 `FrameDetections` 回放的方式。可直接按帧读取
训练录制 MP4，调用 `StationPipeline.process()`，对比事件与人工标注。

## 11. 性能与部署建议

| 项 | 建议 |
| --- | --- |
| 分辨率 | 盘体/槽位区域局部推理优先 |
| 帧率 | 10–15 fps 通常足够；槽位三态依赖连续帧 |
| 硬件 | GPU 可用时优先 GPU；观察 `processing_ms` |
| 丢帧 | 最新帧优先，不积压队列 |
| 模型更新 | 替换权重后重载服务 |

## 12. 明确不做的事

- 不用单帧检测框直接判定取料或二次涂油完成。
- 不用手部停留、刷子出现或预测轨迹单独作为完成证据。
- 不承诺永久稳定的物理物料身份；身份不确定时输出待确认。
- 不把检测 mAP 当作流程验收指标，验收看事件召回率、准确率、待确认率与延迟。
